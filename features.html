Smart Features

Precision irrigation technology for Kenyan farmers

Core Features

Soil Moisture Sensors

Capacitive sensors monitor soil moisture in real-time. Alerts sent when levels drop below crop thresholds.

  • Accuracy ±3%
  • 15min intervals
  • Multi-depth sensing

Auto Irrigation

ESP32 controller opens solenoid valve automatically based on sensor data, weather, and crop needs.

  • Valve duration optimized
  • Multi-zone control
  • Pump protection

Live Dashboard

Mobile-responsive web interface with real-time graphs, irrigation history, and system controls.

  • Live sensor data
  • Historical trends
  • Manual override

SMS Alerts

Critical notifications sent to basic phones - low moisture, irrigation events, system errors.

  • Works on all phones
  • No internet required
  • Custom thresholds

Solar Powered

Complete off-grid operation. Solar panel + battery backup for rural reliability.

  • 10W panel included
  • 48hr battery
  • Low power design

Cloud Analytics

PostgreSQL database stores all readings for trend analysis, yield prediction, system optimization.

  • 1yr data retention
  • AI crop insights
  • Export reports

Technical Specifications

Hardware

ESP32 + Capacitive sensors + Solenoid valve + Solar 10W + Battery 48hr

Backend

PostgreSQL + Node.js API + SMS gateway + Mobile dashboard

Mobile

Progressive Web App + SMS fallback + Offline capable
