Smart Features

Precision irrigation technology for Kenyan farmers

Core Features

Soil Moisture Sensors

Capacitive sensors measure real-time moisture levels. Alerts when critical thresholds reached.

  • Accuracy ±3%
  • 15min intervals
  • Multi-depth sensing

Auto Irrigation

ESP32 microcontroller triggers water valve automatically based on sensor data and weather.

  • Valve duration optimized
  • Multi-zone control
  • Pump protection

Web Dashboard

Live graphs, historical data, irrigation logs. Mobile-responsive ASP.NET dashboard.

  • Live sensor data
  • Historical trends
  • Manual override
Login to Access Dashboard

View live farm data, control irrigation, and monitor sensors after logging in.

SMS Alerts

Critical notifications sent to basic phones - low moisture, irrigation events, system errors.

  • Works on all phones
  • No internet required
  • Custom thresholds

Solar Powered

Complete off-grid operation. Solar panel + battery backup for rural reliability.

  • 10W panel included
  • 48hr battery
  • Low power design

Cloud Analytics

SQLite database stores all readings for trend analysis, yield prediction, system optimization.

  • 1yr data retention
  • AI crop insights
  • Export reports

Backend

SQLite DB + PHP API + SMS notifications + Web dashboard

Mobile

Responsive PWA + SMS fallback + Offline sync
