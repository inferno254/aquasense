About AquaSense

AquaSense is a Kenyan smart irrigation platform that combines soil sensors, real-time data, and automated water control to help smallholder farmers save water, improve yields, and reduce labor.

Designed for rural deployment, it delivers both a mobile dashboard and SMS alerts so farmers can monitor crops with or without a smartphone.

Learn More

Project Objectives

1. Sensor Network Deployment

Deploy soil moisture, temperature, and humidity sensors across the farm to capture field conditions in real time.

2. Microcontroller Control System

Use a central ESP32-based controller to collect sensor data and operate irrigation valves automatically.

3. Web Dashboard Monitoring

Provide farmers with a responsive web dashboard for live soil condition updates, irrigation activity, and system status.

4. Threshold-Based Irrigation

Trigger irrigation automatically whenever soil moisture drops below configured thresholds to protect crop health.

5. SMS Alerts and Status Updates

Send system alerts and basic status updates by SMS so farmers can stay informed even without a smartphone.

Blind Scheduling

Key Features

Soil Moisture Monitoring

Capacitive sensors measure real-time moisture levels. Alerts when critical thresholds reached.

Auto Irrigation

ESP32 microcontroller triggers water valve automatically based on sensor data and weather.

Web Dashboard

Live graphs, historical data, irrigation logs. Mobile-responsive ASP.NET dashboard.

SMS Alerts

Simple SMS for basic phones: "Irrigation ON", low moisture warnings, system status.

Solar Powered

Off-grid operation with solar panel. Works anywhere in rural Kenya.

Cloud Data

SQLite database stores all readings. Analyze trends, predict problems.
