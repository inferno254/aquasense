About AquaSense

Transforming Kenyan agriculture, one drop at a time.

Project Background

AquaSense was born from the urgent need to address water scarcity in Kenyan agriculture. With climate change making rainfall unpredictable and manual irrigation inefficient, small-scale farmers face constant challenges in maintaining crop health.

This project presents an affordable IoT solution that brings precision irrigation to every farm.

"Agriculture is Kenya's backbone. Water is its lifeline. AquaSense makes the connection smart."

Project Objectives

1. Deploy Sensor Array

Install moisture, temperature, and humidity sensors in the field for accurate environmental monitoring.

2. Build Control Intelligence

Develop a central microcontroller system that gathers sensor data and triggers irrigation control elements.

3. Create a Monitoring Dashboard

Deliver an accessible web dashboard for farmers to review real-time field conditions and irrigation status.

4. Implement Auto Irrigation

Automate irrigation when soil moisture falls below thresholds, reducing waste and preventing crop stress.

5. Enable SMS Alerts

Send SMS notifications for low moisture, irrigation events, and system health updates.
